# MGS004NSM-MVS-U4-Bartop-Arcade
Print files &amp; reference for my MVS-U4 inspired Bartop Arcade.

It will take me awhile to update this page with all the relevant info / files required to 3D print and assemble one of these machines.

- STL - 3D print files intended for FDM printing specifically with ABS filament (note the speaker grilles are meant for resin 3D printing)
- SVG - Vector line files for laser cutting or CNC router
